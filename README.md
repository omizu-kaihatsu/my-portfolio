# Portfolio

ChatGPTを活用して企画・制作したWebサイト / Webアプリのデモ集です。

AIに指示を出し出力を確認・修正しながら形にする、という進め方で作っています。

## 制作するにおいて決めていた方針

1. 作りたいもの・誰向けかを自分で決める
2. ChatGPTに指示を出してHTML / CSS / JavaScriptを生成する
3. ブラウザで動かして、表示の崩れや動作のズレを確認する
4. 気づいた点を指示し直して修正する（これを繰り返す）


使用技術：HTML / Tailwind CSS / JavaScriptなど　公開：Netlify
